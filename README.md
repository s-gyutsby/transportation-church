# 국군수송사령부 국군수송중앙교회 통합 사역 포털

전화와 카카오톡으로 분산되어 있던 **상담 예약, 행사 및 세례 접수, 주말 위문 중복 방지, 후원금 안내**를 한곳에서 처리할 수 있는 통합 웹 플랫폼입니다.

---

## 🚀 빠른 시작 방법

### 1. 실행 명령어
터미널에서 아래 스크립트를 실행하면 즉시 서버가 켜집니다.
```bash
./run.sh
```

* **웹사이트 접속 주소**: [http://127.0.0.1:5001](http://127.0.0.1:5001)
* **목회자/관리자 PIN 번호**: `1111` (우측 상단 '목회자/관리자' 버튼 클릭 후 입력)

## 📌 주요 핵심 기능 안내

### 1. 1:1 신앙·마음 상담 시스템 (보안 및 구글 캘린더 연동)
* **목사님 가용 시간대 슬롯 선택**: 관리자 패널에서 설정한 시간대만 신청자에게 표시됩니다.
* **군 특수성 비밀 보장**: 가명 신청 지원 및 신청자가 설정한 **4자리 비밀번호**로 언제든 `[내 신청 내역 조회]`에서 진행 상태를 비밀 조회할 수 있습니다.
* **구글 캘린더 원클릭 추가**: 관리자 화면에서 `[📅 구글캘린더 추가]` 버튼을 누르면 상담 일정과 신청자 정보, 고민 내용이 채워진 구글 캘린더 등록 창이 즉시 열립니다.
* **목사님 비공개 상담 일지**: 상담 후 목사님만 볼 수 있는 메모를 기록하고 저장할 수 있습니다.

### 2. 주말 위문 방문 중복 방지 시스템
* **실시간 주말 캘린더 (8주간 토/일)**:
  * 🟢 **신청 가능**: 아직 위문 신청이 없는 빈 슬롯
  * 🟡 **조율 중**: 신청 접수 후 목사님 검토 대기 상태
  * 🔴 **예약 마감**: 목사님 승인 완료 시 즉시 마감되어 **다른 단체의 중복 신청이 원천 차단**됩니다.
* **중복 간식 방지**: 방문 단체가 가져올 위문품/간식 품목을 사전에 필수 입력받아 인접 주차와 간식이 겹치지 않도록 조율할 수 있습니다.

### 3. 정기 예배 및 특별 행사 접수
* **정기 예배 타임테이블**: 주일 1/2부, 수요기도회, 새벽기도 등 안내
* **선착순 참가 접수**: 세례식, 동계 수련회, 찬양팀 모집 등 실시간 정원 프로그레스 바 표시 및 정원 마감 처리
* **참가자 명단 엑셀(CSV) 다운로드**: 부대 행정 보고용으로 한글 깨짐 없는 Excel 호환 CSV 파일 원클릭 다운로드 지원

### 4. 후원금 계좌 안내 및 입금 알림
* **우리은행 공식 계좌 원클릭 복사**: `1002-111-884400` (국군수송중앙교회)
* **후원 완료 통보서**: 후원자가 입금 후 성함과 기도제목을 남기면 목사님 관리자 대시보드로 즉시 전달
* **우리WON뱅킹 무료 푸시 알림 가이드**: 목사님 스마트폰에서 1분 만에 설정하여 입금 즉시 알림을 받을 수 있는 상세 가이드 모달 제공

### 5. 목회자 3인 프로필
* 담임 군종목사(소령), 부목사(대위), 교육/위문 협력목사 3인의 가상 프로필과 말씀 구절, 인사말 탑재

## 🛠️ 관리자 패널 사용 안내 (PIN: 1111)
홈페이지 우측 상단 **[🔒 목회자/관리자]** 버튼을 클릭하여 PIN `1111`을 입력하면 관리자 대시보드로 진입합니다.
1. **상담 관리**: 신청 승인, 구글 캘린더 추가, 비공개 상담 메모 저장
2. **위문 관리**: 주말 위문 신청 승인 (승인 시 즉시 슬롯 닫힘)
3. **행사 관리**: 참가자 명단 확인 및 엑셀(CSV) 다운로드
4. **후원 관리**: 성도님들이 남긴 후원 통보 및 기도제목 확인
5. **시간대 설정**: 요일별 상담 가능 시간대 추가/삭제/토글
